## [trynix.dev 让任意 Nix 软件包在浏览器虚拟机中运行](https://simonwillison.net/2026/Sep/10/trynix/) ⭐️ 8.0/10

Farid Zakaria 发布了 trynix.dev，它借助 qemu-wasm 项目，通过 WebAssembly 在浏览器内运行一个完整的 x86_64 Linux 虚拟机，并能用过去 13 年间构建的任意 Nix 软件包来启动这个虚拟机。软件包是可被 URL 寻址的，例如访问 https://trynix.dev/?pkg=python3%403.6.2 就能获得一个运行 2017 年 Python 3.6.2 的交互式 shell；配套的 GitHub Action 名为 trynix-preview，会在 Pull Request 下评论这样一个链接。 它把“软件考古”和可复现调试变成了点一下链接的事：开发者或评审者不必在本地重建旧工具链，只要打开一个 URL 就能运行当年的确切软件包版本。trynix-preview 这个 GitHub Action 又把能力延伸到代码评审，让评审者能在无需服务器的浏览器沙箱中直接启动某个 PR 的构建产物，这对 Nix 生态以及整个可复现性实践而言，都是体验上的显著提升。 整个环境依赖 qemu-wasm，它把 QEMU 的 x86_64 系统模拟器编译为 WebAssembly，因此性能受模拟器限制，无法与原生安装相比；用户需要点击 “Load” 才会触发启动，而 13 年的时间跨度对应 Nix 二进制缓存与固定版本（pinned revision）所能提供的软件包范围。作者本人称该项目是他 Nix 工作中的“代表作（magnum opus）”。

rss · Simon Willison · 9月10日 23:44

**背景**: Nix 是 Eelco Dolstra 于 2003 年创建的跨平台、纯函数式包管理器，它把每个软件包安装到各自唯一且以内容寻址的存储路径中，从而实现构建可复现，并允许同一软件的多个版本共存。正是这一特性让 trynix.dev 成为可能：因为 Nix 能够可靠地重建和获取准确的历史版本，站点才能提供横跨多年的软件包目录。QEMU 是通用的机器模拟器与虚拟化工具，而 qemu-wasm 是它的一个移植版本，通过 WebAssembly 在浏览器中运行，因此整个虚拟机是在客户端本地执行的，不需要任何后端服务器。

## [单卡从零训练 210M 文生图 DiT，给出三项新测量结果](https://www.reddit.com/r/MachineLearning/comments/1wdfmvq/training_a_210m_texttoimage_dit_from_scratch_on/) ⭐️ 8.0/10

一位开发者用单张 RTX PRO 6000 显卡、耗时 3.5 天、以 420 万张 256² 图像从零训练出一个 2.1 亿参数的文生图扩散 Transformer（DiT），并且公开的不是生成样例而是三项测量结果。这三项结论分别是：附加在交叉注意力上的两个可学习 key/value 槽位在中等噪声水平下吸收了约 90% 的交叉注意力权重（通常作为汇点（sink）的 EOS token 降至约 4%）；流匹配损失反映的是训练健康状况而非生成质量；训练时使用的 timestep shift 带来的收益超过把采样步数翻倍。 它说明如今不依赖集群、只用一张接近消费级的显卡也能开展有价值的扩散 Transformer 研究并做可复现的消融实验，从而降低了独立研究者的门槛。关于注意力汇点（attention sink）和 register token 的测量结果，也为“空槽位如何稳定交叉注意力”提供了具体的量化证据，这对调试或压缩文本条件扩散模型的人都直接有用。 该模型采用交叉注意力 DiT（宽度 896、16 个 block）、2D RoPE、QK-norm、SwiGLU、adaLN-single、带 logit-normal 时间步的整流流（rectified flow），图像流中有 16 个 register token，并使用五种宽高比分桶；到中间 block 时，register 向量的范数已增长到图像 token 的 4–13 倍。整轮训练中流匹配损失仅从 0.805 降到 0.754，而留出集 FID 从 33.7 降到 27.0、FD-DINOv2 从 570 降到 218、基于检测器的物体准确率从 65% 升到 90%；在 20 步采样下，shift 2.8 得到 FID 27.0，而无 shift 为 27.3（FD-DINOv2 分别为 218 与 228），其中 shift 2.8 来自针对 32 通道 FLUX.2 latent 的 SD3/RAE 公式 √(32·32·32/4096)。

reddit · r/MachineLearning · /u/IvanMikhnenkov · 9月11日 13:00

**背景**: 扩散 Transformer（DiT）是一类生成模型，它用 Transformer 主干取代经典扩散模型中的卷积 U-Net，通过对以文本为条件的潜表示反复去噪来生成图像。注意力汇点（attention sink）是指那些几乎不携带信息、却吸收了不成比例注意力权重的 token；register token 则是额外的、与输入无关的 token（由《Vision Transformers Need Registers》一文提出），为模型提供一个专门容纳此类全局记账信息的去处，从而减少伪影。流匹配／整流流（flow matching / rectified flow）训练模型回归从噪声到数据路径上的速度场，而 timestep shift 是采样阶段对噪声水平的重新加权（由 SD3 推广），会改变所需采样步数；FID 是常用的分布距离指标，数值越低越好。
