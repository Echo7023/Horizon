## [Samsung and SK Hynix Reportedly to Adopt YMTC's Xtacking for 3D NAND](https://t.me/zaihuapd/45377) ⭐️ 8.0/10

Samsung Electronics and SK Hynix have reportedly agreed, through a cross-licensing arrangement, to adopt parts of YMTC's Xtacking wafer-bonding technology in their 3D NAND flash production. All three companies declined to comment on the reports, so the deal remains unconfirmed officially. If confirmed, it would mark a rare case of a Chinese memory maker licensing core process technology to the two dominant Korean NAND producers, signaling that YMTC's hybrid-bonding approach has become hard to ignore. It could accelerate the industry-wide shift away from conventional single-wafer NAND manufacturing and reshape where key IP in 3D NAND sits. Xtacking builds the memory-cell array and the CMOS logic circuitry on two separate wafers that are then bonded together, allowing each half to be manufactured and optimized independently. An Omdia senior analyst noted this lets a vendor fab its own array while outsourcing the logic die to a foundry, gaining access to more advanced process nodes; cost and yield of the bonding step remain the main trade-offs versus the simpler CMOS-under-array approach.

telegram · zaihuapd · Nov 26, 05:30

**Background**: 3D NAND flash is built by stacking memory cells vertically to raise density, and the peripheral CMOS circuitry that drives those cells has traditionally been placed either beside the array or underneath it (CMOS-under-array). A newer alternative is to fabricate the CMOS wafer and the NAND array wafer separately on their own optimized processes, then join them with wafer-to-wafer hybrid bonding using dense copper-to-copper contact pads. YMTC, a Chinese NAND maker, pioneered this split-wafer approach under the name Xtacking.

## [AMD-specific llama.cpp fork targets cheap gfx906 HBM2 datacenter GPUs](https://devnull.land/amd-specific-llama-cpp) ⭐️ 7.0/10

A developer published an AMD-specific fork of llama.cpp tuned for the gfx906 datacenter GPU series (the 2018-era Vega 20 chips used in Instinct MI50/MI60 and Radeon VII), which lack tensor cores and native bf16 support. The fork squeezes usable local LLM inference out of second-hand cards that offer 32 GB of HBM2 at roughly 1 TB/s bandwidth for around $200. Token decoding for local LLMs is memory-bandwidth bound, so old high-bandwidth accelerators can rival far more expensive modern cards at a fraction of the price. This fork lowers the barrier to running large quantized models locally and highlights how community optimization can extend the useful life of hardware that AMD's own software stack has largely moved past. Because gfx906 has no matrix cores and no native bf16, the fork has to rely on hand-tuned kernels and quantization-aware paths rather than the tensor-core fast paths used on NVIDIA or newer AMD hardware. Expect it to remain a niche, maintenance-heavy effort whose performance depends heavily on the specific model, quantization format, and ROCm version in use.

hackernews · julianlam · Nov 26, 17:11 · [Discussion](https://news.ycombinator.com/item?id=50657265)

**Background**: llama.cpp is an open-source C/C++ inference engine built on the ggml library that runs quantized GGUF models with minimal setup across a wide range of hardware, from CPUs to GPUs. gfx906 is the LLVM target name for AMD's Vega 20 architecture, sold in 2018–2019 as the Instinct MI50/MI60 datacenter cards and the Radeon VII, which paired modest compute throughput with HBM2 stacked memory offering very high bandwidth. HBM2 is a 3D-stacked DRAM interface that delivers far more bandwidth than GDDR or system memory, which is exactly what memory-bound LLM decoding benefits from most.

If frontier labs optimize primarily for cost per token rather than peak capability, teams that select models mainly on price could see real regressions in day-to-day coding work. The debate matters to anyone paying API rates, since it signals a possible shift from a capability race to a price-and-efficiency race among the big model providers. Commenters pointed out that the release in question may have been a timed launch scheduled around an external event (described as an "ANT IPO"), and speculated the model was undercooked rather than fundamentally worse. hackernews · seizethecheese · Nov 26, 07:33 · [Discussion](https://news.ycombinator.com/item?id=50652527)

**Background**: Frontier AI labs publish models that sit on a tradeoff curve between how capable they are and how much each token costs to serve; the set of models that are not beaten on both dimensions at once is called the Pareto frontier. Because API customers pay per token, a cheaper model that is slightly less capable can be the rational choice — which is why labs increasingly market benchmark scores alongside pricing. Benchmarks, however, are proxies for real work, so a model can look competitive on paper while feeling worse in practice, as several commenters reported for coding tasks.

## [FCC Approves SpaceX's Expanded Gen2 Starlink for Gigabit-Class Service](https://t.me/zaihuapd/45375) ⭐️ 7.0/10

On Friday, the U.S. Federal Communications Commission (FCC) partially granted SpaceX's application, allowing the company to deploy an additional 7,500 second-generation (Gen2) Starlink satellites, bringing the total Gen2 constellation to 15,000. The approval also lets those satellites operate in lower orbits to improve performance and clear a path toward gigabit (1 Gbps) download speeds for Starlink users. This is one of the largest single expansions of a commercial satellite broadband constellation ever authorized, and it strengthens Starlink's position against rivals such as Amazon's Project Kuiper and OneWeb in the race to serve rural and underserved broadband markets. Faster speeds and more capacity could make satellite internet a more credible substitute for terrestrial fiber and cable in areas where those networks are uneconomical to build. The approval is only partial — the FCC granted a subset of SpaceX's requested Gen2 modifications rather than the full application — and it attaches deployment milestones that require SpaceX to launch satellites on a schedule or risk losing authorization. Doubling the Gen2 constellation and lowering orbital altitudes can reduce latency and increase per-user throughput, but delivering true gigabit speeds will depend on ground terminals, beam capacity and backhaul, not satellites alone.

telegram · zaihuapd · Nov 26, 04:45

**Background**: Starlink is SpaceX's low-Earth-orbit (LEO) satellite internet service; because LEO satellites sit only a few hundred kilometers up rather than in geostationary orbit some 35,000 km away, they offer far lower latency. A "constellation" is the collective fleet of satellites working together, and "Gen2" refers to SpaceX's second-generation design, which is larger and more capable than the first-generation satellites but requires regulatory approval for new orbits and frequencies. The FCC licenses commercial satellite systems in the United States, so SpaceX cannot deploy new satellites or orbital shells without its sign-off.

## [Preprint claims algebraic quantization of gravity on null cones](https://arxiv.org/abs/2611.34924) ⭐️ 6.0/10

A new arXiv preprint (2611.34924) by Venkatesa Chandrasekaran proposes a background-independent quantization of vacuum general relativity on four-dimensional Lorentzian spacetimes. It solves the gravitational constraints on intersecting null cones to obtain a reduced phase space at finite Newton constant, promotes the Poisson brackets to commutators, and constructs an algebra of observables using deformations of the reduced action and Gaussian wavefunctions. If valid, this would be a significant step toward a background-independent quantum theory of gravity and could connect black hole entropy and area quantization to a concrete algebraic framework. Because it is an unreviewed preprint, however, the claim is being treated cautiously, and its reception will shape debates about both quantum gravity and AI-assisted theoretical physics. The paper works at finite G_N on intersecting null cones of a bulk subregion, studies a causal-diamond Hilbert space with a claimed discrete area spectrum and black hole entropy, and argues for finiteness of transition amplitudes. Commenters question why the observable algebra is Type I rather than the Type II expected when gravity is included, and whether the Lorentzian path integral and background independence are rigorously established; coverage also notes that the acknowledgments thank OpenAI's GPT-6 Astra, which has fuelled the AI-focused debate.

**Background**: Quantum gravity seeks to unify general relativity, which describes gravity as curved spacetime, with quantum mechanics, which describes matter and forces through operators and probabilities. A null cone, or light cone, is the surface swept out by light rays from a point and can be used to specify initial data for gravitational fields; intersecting null cones bound a causal diamond. Algebraic quantization describes a theory through an algebra of observables and its Hilbert-space representations, and von Neumann algebra types (Type I, II, III) classify such algebras and control properties like entropy and finiteness. In quantum field theory with gravity, Type II algebras have recently played a central role because they can yield finite entropy.

## [sqlite3_rsync: Remote SQLite snapshots without doubling disk space](https://simonwillison.net/2026/Nov/26/sqlite3-rsync/) ⭐️ 6.0/10

Simon Willison highlighted an underappreciated property of SQLite's experimental sqlite3_rsync tool: it can copy a snapshot of a database to another machine over SSH without first creating a full local duplicate. The tool was originally added as experimental in SQLite 3.47.0 (October 2024) and enhanced in SQLite 3.50.0 (May 2025), so this is an explainer rather than a new release. Traditional approaches to snapshotting a SQLite database — the backup API and VACUUM INTO — both require enough free disk to hold a full duplicate, which is impossible on small instances already using more than half their storage. sqlite3_rsync removes that constraint, making remote backups and replica synchronization practical for resource-constrained deployments such as edge devices, small VPS instances, and embedded systems. The protocol mirrors rsync: the replica sends cryptographic hashes of pages or page groups to the origin, which returns only differing page content or requests finer-grained hashes when a multi-page hash fails to match. If the two sides start out vastly different, total bandwidth can slightly exceed the full database size due to hash-exchange overhead, but the excess is only a few percent at most.

rss · Simon Willison · Nov 26, 06:08

**Background**: SQLite is a self-contained C library that implements a full SQL database engine without a separate server process, and it is widely described as the most deployed database engine in the world. Because a SQLite database is a single file, taking a consistent backup while it is in use normally requires special mechanisms rather than a simple file copy. The backup API and VACUUM INTO both produce a consistent copy, but each writes a complete new database file locally, doubling the required disk space. sqlite3_rsync instead streams changes over SSH using a hash-based diff protocol, in the same spirit as the classic rsync utility.
